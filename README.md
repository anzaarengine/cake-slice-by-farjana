## ✨ Features & Architecture

### 1. 🎨 Studio 4:5 (Single Post Generator)
- **Strict 4:5 Editorial Portrait Ratio**: Formatted precisely for Instagram and Facebook feeds.
- **25% / 75% Breathing Space Rule**:
  - **Bottom 25%**: The customer's cake is anchored on an artisanal natural base, preserving original frosting and textures with natural drop shadows.
  - **Top 70%–75%**: Seamless, massive negative space dedicated to brand typography.
- **Natural Base Variety**:
  - Hand-carved Dark Wood Block
  - Raw Travertine Stone Slab
  - Matte Black Ceramic Pedestal
  - Light-Oak Timber Block
  - Matte Terracotta Platter
  - Artisanal Slate Stone Slab
- **Locked Aesthetic Styles**:
  - **Style 1: Dark & Warm Cinematic** (Charcoal gradient, warm golden cinematic side-light).
  - **Style 2: Organic Earth Tone** (Warm taupe/sand plaster, soft diffused ambient wrap).
- **Locked Bengali Typography Styles**:
  - **Style 1: Brush Strokes / Artistic Brush** (Off-white & light-gold dual tones, 3D bristle depth).
  - **Style 2: Fluid / Liquid** (Rich dark-brown & warm gold curves, organic flowing letters).
  - **Style 3: Handwritten / হাতে আঁকা** (Artisanal calligraphy with whimsical curls and signature intimacy).
- **Direct High-Res 4:5 Export**: Download crisp 1080x1350 PNG images with one click.
- **Master 8K AI Prompt Generator**: Instant one-click copy of the locked photorealistic prompt for Midjourney / FLUX / Imagen.

### 2. 📑 Carousel & Multi-Image Studio (3–4 Photos)
- Upload 3 to 4 angles of the same cake (Hero, Texture, Slice Cut, Styling).
- **Carousel Mode**: Coordinated 4:5 swipe cards (Cover + Texture detail + Craft story + Reserve/Order CTA).
- **Collage Mode**: 3-in-1 luxury magazine grid on a single 4:5 canvas.
- Instant 1-click download pack.

### 3. 🎬 Reels & Video Studio (9:16 Shorts)
- Upload raw mobile/camera footage.
- **9:16 Vertical Safe-Zone Framing**: Instagram & TikTok overlay previews.
- **Gemini Pro Reels Director**:
  - 3-second scroll-stopping hook idea.
  - Timestamp cut plan (e.g. 0:00–0:02 Hook, 0:02–0:08 Drizzle/Cut, 0:08–0:15 Hero reveal).
  - Luxury audio & music mood suggestions (Lo-Fi Classical, Warm Jazz, ASMR).

### 4. ✍️ Gemini Pro AI Copywriter
- Select editorial tone (*Artisanal Editorial*, *Royal Celebration*, *Minimalist Chic*, *Behind The Craft*).
- Select language (*নান্দনিক বাংলা*, *Banglish*, *Luxury English*).
- Generates:
  - Scroll-stopping opening hook.
  - Sensory storytelling body.
  - Order / Booking invitation CTA.
  - High-reach bakery SEO hashtags.

### 5. 🔑 Safe Gemini Pro API Key Integration
- Add your Google AI Studio / Gemini Pro API key once.
- Stored safely in browser `localStorage` (never transmitted to third-party servers).
- Switch between `gemini-2.5-flash`, `gemini-1.5-pro`, and `gemini-2.5-pro` with live connection testing.

## 🌐 Free 1-Click Deployment to Vercel

1. Push this repository to your **GitHub** account:
   ```bash
   git add .
   git commit -m "feat: Cake Slice by Farjana Brand Content OS"
   git remote add origin https://github.com/<your-username>/cake-slice-by-farjana.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository (`cake-slice-by-farjana`).
4. Click **Deploy** (No environment variables required initially — you can enter your Gemini API key directly in the web app UI settings!).
5. Done! Your personal Content OS is now live on a free `.vercel.app` domain and accessible anywhere from your phone or computer.
